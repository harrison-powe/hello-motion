# AGENTS

This repo is a public hardware notebook for hello-motion.

Do not claim hardware has been selected, bought, assembled, tested, measured, or controlled unless the repo records that evidence.
Keep `README.md` status-bearing and honest. It carries a Status list marking
each milestone complete, partial, or untouched, plus one deep-dive on a
genuinely interesting failure. It may only claim what the repo can evidence;
anything unmarked is not claimed. Detail belongs in `logs/`, `docs/`,
`data/`, `cad/`, `media/`, and `bom/` — the README summarises and links.
Use `logs/` for chronological build notes, and use domain folders for durable artifacts.
Do not add secrets, credentials, private notes, account identifiers, personal data, or a license without explicit approval.
